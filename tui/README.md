# enil-tui

在終端機用 LINE。ratatui + crossterm。

```
╭ LINE · 未讀 3 ─────────────────╮╭ 週末爬山團 ───────────────────────────────────╮
│▌ 週末爬山團               05:52││            ──────  10/02 週五  ──────         │
│▌ 小安：那就約七點捷運站見      ││▎ 小安  05:04                                  │
│  Alice                   05:14││▎ 七星山？路線在這 https://example.com/trail ↗ │
│  水餃在冰箱                  3 ││▎ 東峰主峰都走                                 │
│  阿哲                     09/29││                                               │
│  好喔                          ││▎ 我  05:09                                    │
│                                ││▎ 好，我可以                                   │
│                                │╰───────────────────────────────────────────────╯
│                                │╭───────────────────────────────────────────────╮
│                                ││› 傳訊息給 週末爬山團…                         │
╰────────────────────────────────╯╰───────────────────────────────────────────────╯
 對話  週末爬山團  Enter 送出   Tab 選附件 ↗   Esc 返回                  ● 已連線
```

排法參考 [slk](https://github.com/gammons/slk)：訊息全部靠左，靠名字的顏色分人；
同一個人五分鐘內連續發的只顯示一次名字；最底下一條狀態列。

每組訊息前面有發話者的大頭貼（4×2 格，daemon 抓好放在 `media/avatar-*`）。
對方沒設照片時畫名字的第一個字。清單也有：一對一是對方的照片，群組是群組圖；
收窄（Ctrl-B）時不畫。

視窗寬度在 50 欄以內時改成單欄：沒開聊天室顯示清單，開了就只顯示對話，Esc 回清單。
拉寬回來會自動變回兩欄。門檻是 `main.rs` 裡的 `NARROW_COLS`。

## 配色

在 omarchy 上會跟著系統主題走，換主題時不用重開：

- 發話者顏色與調暗用終端機調色盤的色號。omarchy 換主題時會叫終端機重載調色盤，
  這些顏色自己就會變。
- 強調色與選取底色不在調色盤裡，從 `~/.local/state/omarchy/current/theme/colors.toml`
  讀（`accent`、`selection`、`background`），每秒看一次檔案有沒有變。

不是 omarchy（沒有那個檔）就全部用調色盤的色號，強調色是綠色。

## 這支程式不碰 LINE

它只是 [enil](https://github.com/Unayung/enil) daemon 的消費者，走 unix socket
收發一行一個 JSON —— 跟 omarchy 外掛同一個契約。登入、E2EE、輪詢都在 daemon 那側。

daemon 還沒登入時，TUI 會先顯示登入畫面：按 Enter 跟 daemon 要 QR，掃完在手機上輸入
畫面上的 PIN，登入後自動進主畫面。QR 用圖片協定畫；終端機不支援時改看畫面上那行網址。

所以需要 daemon 在跑：

```bash
systemctl --user status enil
```

## 建置與執行

```bash
cargo build --release
./target/release/enil-tui
```

## 操作

```
j/k 或 ↑↓   選聊天室（右邊直接預覽它的訊息，不標已讀；Enter 才是進入）
             聊天室開著時用 ↑↓ 或滾輪也一樣：右邊預覽選中的那個，輸入框暫停收字
             （免得以為在跟它說話卻送到原本的聊天室），Enter 進入，Esc 回到原本的
Enter        開啟聊天室；聊天室開著且輸入框有字時＝送出
Tab / Shift-Tab  選一則訊息（Tab 從最新的開始），Esc 取消選取。選中之後：
               r 表情回應（1 👍 2 ❤️ 3 😆 4 😮 5 😢 6 😱，0 取消自己的回應）
               d 收回（自己的訊息；按兩下才送，LINE 只能收回 24 小時內的）
               Enter 開附件或連結（標 ↗ 的）；語音會在背景播，再按一次停
@            群組裡打 @ 挑人提及（打字篩選，Enter 選，Esc 就只留一個 @）
Ctrl-S       搜尋訊息內容：搜的是 daemon 的本機存檔，比 LINE 伺服器保留的兩週更早的也找得到
滑鼠點訊息   直接開啟（滑到點得開的東西上，指標會變成手指）
/            搜尋全部聊天室（不只清單上最近的 60 個）；聊天室開著時要輸入框是空的
? 或 F1      按鍵說明（? 只在清單模式；聊天時 ? 是要打的字，用 F1）
             螢幕放不下整份說明時 j/k、方向鍵、PgUp/PgDn、滾輪捲動；Esc／q／Enter 關閉
← → Home End  移動輸入框的游標（Ctrl-← → 跳一個詞，Ctrl-A／E 到開頭結尾）
Ctrl-W/U/K   刪前一個詞／刪到開頭／刪到結尾
Ctrl-V       貼上：剪貼簿裡的圖片、或在檔案管理員複製的檔案，會變成附件；文字進輸入框
Ctrl-F       附加檔案：輸入路徑，Tab 補完
拖檔案進終端機  附加那個檔案（終端機貼進來的是路徑，TUI 認得）
Ctrl-B       清單：展開 → 只有名稱 → 隱藏（對話最大化）
g            往前載入更舊的訊息（輸入框空的時候）
r            重整聊天室清單
滾輪／PageUp Down  捲動訊息（往上＝回溯較舊的）
Esc          回到清單（輸入框打到一半的字會留給那個聊天室，回來時還在）
Ctrl-C       離開
```

附件會以標籤顯示在輸入框最前面，Enter 送出（有打字的話，附件先送、文字後送），
Esc 或在空的輸入框按 Backspace 取消。切到別的聊天室時附件會被丟掉，免得送錯人。
讀剪貼簿靠 `wl-paste`，所以 `Ctrl-V` 貼圖只有 Wayland 能用；拖放與 `Ctrl-F` 不受限。
貼上多行文字時，輸入框裡換行顯示成 `⏎`，送出去是真的換行。

新訊息由 daemon 推送（`subscribe`），清單與開著的聊天室會即時更新；另外每 60 秒
跟伺服器對齊一次未讀數。進入聊天室會自動標為已讀。OpenChat 不在推送範圍內。

視窗沒有焦點、或訊息不在開著的聊天室時，會送 OSC 9 桌面通知（ghostty、WezTerm、
iTerm2 認得；kitty 與 foot 用的是別的序列，目前不會跳）。

自己發的訊息右側顯示已讀（一對一「已讀」、群組「已讀 3」）；別人的訊息 @ 了你就標「@你」；
有表情回應的在下方統計（`👍 2  ❤️`）。對方讀了、回應了、編輯了，開著的聊天室會在一兩秒後
自己重讀（往上捲著的時候不重讀，免得把載入的舊訊息丟掉）；收回則是立刻換成「[已收回]」。

## 訊息型別

| 型別 | 顯示 | 開啟（↗） |
|---|---|---|
| 圖片 | 縮圖 | 下載原圖 |
| 貼圖 | 小圖 | — |
| FLEX | 第一張圖＋卡片裡的文字 | 第一個連結 |
| RICH | altText | — |
| 檔案 | `[檔案] 檔名（大小）` | 下載 |
| 影片 | 預覽圖＋`[影片]（大小）` | 下載 |
| 語音 | `[語音]` | 下載 |
| 通話 | `[通話] 1:49`／`[通話] 未接通` | — |
| 文字裡有網址 | 原文 | 第一個網址 |

開啟一律交給 `xdg-open`（macOS 是 `open`），只開 `http(s)` 連結。

## 圖片

訊息裡的圖片會直接畫在終端機裡（`ratatui-image`）。協定自動偵測：

| 終端機 | 用什麼 |
|---|---|
| ghostty、kitty、WezTerm | Kitty graphics protocol |
| foot、xterm | Sixel |
| 其他 | 半格字元（`▀`，粗但看得出是什麼） |

圖檔來自 daemon —— 讀歷史時就把縮圖抓好放在 `~/.local/state/enil/media/`，
TUI 只是把本機檔案畫出來。

偵測會向終端機送查詢並等回應。**沒有回應者的環境（某些 pty、測試腳本）會把輸入
狀態弄壞**，用 `ENIL_TUI_HALFBLOCKS=1` 略過查詢：

```bash
ENIL_TUI_HALFBLOCKS=1 ./target/release/enil-tui
```

## 設計筆記

- **每個請求開一條新連線**。daemon 支援並行連線，這樣就不必自己管單一連線上的
  請求／回應配對。
- **網路請求都在背景執行緒**。daemon 抓歷史要跟 LINE 來回一趟，同步做會把 UI 卡住。
- **有日期分隔**。只顯示 `HH:MM` 的話，昨天 19:30 排在今天 15:01 前面會看起來像亂序。
- **訊息區是逐則排版，不是單一 Paragraph**。圖片需要自己的 `Rect`，塞不進一個
  可捲動的文字區塊。由下往上堆（聊天看的是最新的），捲動＝從底往上跳過幾則。
- 時間換算沒有拉進 chrono —— 只需要台北時區的 HH:MM 與 MM/DD，自己算比多一個依賴划算。
